결과 해석

정확도를 우선한다면 적용을 검토할 근거가 생겼습니다. 30문항에서 성공은 26개에서 28개로 늘었고, 1위 정답은 17개에서 24개로 늘었습니다. 문항별 RR@5는 10개 개선, 19개 동일, 1개 하락했습니다. 기존 성공 문항이 실패로 바뀐 사례는 없습니다.

상위 주제 키워드인 A는 두 방식 모두 100%로 차이가 없었습니다. 구체적인 B+C 20문항에서는 Hit@5 80% → 90%, MRR@5 0.505 → 0.800으로 개선됐습니다. 기존 24문항에서도 Hit@5 17/24 → 21/24, MRR@5 0.4417 → 0.7917로 개선돼, A의 넓은 정답 범위만으로 설명되는 상승은 아닙니다.

키워드 검색이 놓친 후보를 보충

벡터 10개만으로는 30문항 중 25문항의 정답을 후보에 포함했습니다. 키워드 검색을 합치자 28문항이 됐고, 리랭크가 이 28문항 모두를 최종 5개 안으로 올렸습니다. B08 트렁크 높이 저장, C02 캠핑 전력 제한, C08 앞유리 습기 제거의 정답은 벡터10에 없고 키워드10에 있었습니다.

후보 수·키워드 생성·통합 방법·리랭크를 함께 바꾼 묶음 비교입니다. 점수 상승 전부를 리랭크 하나의 효과라고 단정하지 않습니다. 키워드 검색이 후보를 보충한 사례와, 확보된 후보의 순위가 올라간 사례를 분리해 관찰했습니다.

남은 실패는 후보 확보 단계

B05 · 스마트키 건전지 규격: AI는 ‘스마트키·건전지·규격’을 추출했지만, 정답 본문은 ‘스마트 키·배터리·CR2450’이라고 씁니다. 띄어쓰기와 동의어가 달라 LIKE 검색이 정확한 근거를 확보하지 못했습니다. 같은 PDF 159쪽의 주의사항 청크를 1위로 찾았지만, 규격이 적힌 정답 청크는 후보에 없었습니다. 페이지 기준이면 성공처럼 보여도 이번 청크 기준에서는 실패입니다.

C03 · 차 안 노트북 충전 콘센트: 검색어는 ‘노트북·충전·콘센트’인데 정답은 ‘차량 내부 전원 패널·전원 소켓·V2L’로 표현됩니다. 일부 검색 결과는 ‘노트북’이 언급된 에어백 경고문으로 흘렀습니다. 정답이 후보에 없으므로 순서를 다시 정하는 리랭크로 복구할 수 없습니다.

기존 24문항의 추가 실패 G19(브레이크로 감속 중 패들 조작)도 정답이 통합 후보에 없었습니다. 이 실험에서는 통합 후보에 정답이 있는데 최종 5개 밖으로 밀려난 실패는 없었습니다.

속도와 다음 비교 방향

30문항 평균 키워드 추출 AI는 2.85초, 리랭크 AI는 4.93초, 읽기 전용 검색 실험 전체는 8.27초였습니다. 현재 로컬 방식보다 모델 호출이 두 단계 늘어납니다. 이번에는 임베딩과 벡터 조회를 캐시로 대체했으므로, 이 숫자를 실제 챗봇 전체 응답 시간으로 해석하면 안 됩니다.

현재처럼 응답 속도도 중요하다면 바로 전면 교체하기보다는, 다음 실험에서 현재 TF-IDF 후보를 유지한 채 리랭크만 더하는 방식과 비교할 수 있습니다. 그렇게 하면 키워드 추출 AI 한 번을 줄일 수 있지만, 점수가 유지되는지는 아직 측정하지 않았습니다. 띄어쓰기 정규화·동의어 처리·후보 확대 역시 후속 실험 후보이며 이번 결과에는 적용하지 않았습니다.
