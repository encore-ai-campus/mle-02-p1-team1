점수는 정답지 구성에 따라 달라집니다.
검색 24문항과 행동 24문항은 따로 채점합니다. 기존 예비셋을 포함하므로 독립 최종 테스트셋이 아닙니다. 질문·정답·채점 규칙을 검토한 뒤 고정하고, 같은 세트로 개선 전후를 비교하세요.

구분문항 수평가 방법

채점 규칙

  • 상위 5개 안에 정답 청크 ID가 하나라도 있으면 Hit=1, 아니면 0. 24문항 평균이 Hit@5입니다.
  • 첫 정답 순위가 r이면 1/r. MRR@5는 5위 밖이면 0, 전체 MRR은 전체 순위를 사용합니다. 두 수치를 혼용하지 않습니다.
  • 같은 페이지나 같은 부모라는 이유만으로 정답으로 인정하지 않습니다. 질문에 답할 수 있는 핵심 근거가 있어야 합니다.
  • 그림 청크는 픽셀 자체가 아니라 캡션/연결 본문으로 검색됩니다. 핵심 근거를 담은 이미지 설명 청크는 인정합니다.
  • 정답 문장을 그대로 복사했는지보다 의미·수치·조건·출처가 맞는지 봅니다. 행동 평가에서 raw action 값과 사용자에게 실제로 보이는 답변의 적절성을 따로 기록합니다.
  • 이번 48문항은 모두 이전 대화가 없는 독립 질문입니다. 동일 질문 순서대로 한 세션에 넣지 마세요. 다중턴 평가는 별도로 구성해야 합니다.
  • 추가 정답을 발견하면 새 버전으로 남기고 비교할 모든 방식에 똑같이 재채점합니다. 점수를 높이기 위해 실패 질문을 빼지 않습니다.

검토와 실행

원문 PDF 페이지는 뷰어 기준(1부터 시작)입니다. 종이에 적힌 쪽수와 다를 수 있습니다. 근거 청크 본문은 아래에서 펼쳐 확인할 수 있습니다. 24개의 원문 근거 문구와 현재 DB 청크를 확인했지만, 대체 근거 누락 여부와 행동 기준은 팀 검토가 필요합니다.

G19는 기존 SNOW 모드 질문 대신 동일 근거의 브레이크 감속 조건을 묻습니다. 새 결과를 기존 v1 점수와 직접 비교하지 말고 같은 v2로 기준 방식과 개선 방식을 모두 실행하세요.

자동 검색 평가에는 retrieval_dataset.json만 사용합니다. 전체 48개는 golden_dataset.json입니다. 이번 작업에서는 검색/LLM 평가를 실행하지 않았습니다.

검색 평가 실행 명령
.venv/bin/python src/car_search_rag/anna_rag/evaluation/evaluate_retrieval.py \
  --dataset src/car_search_rag/anna_rag/evaluation/golden_v2/retrieval_dataset.json \
  --output src/car_search_rag/anna_rag/evaluation/m6_golden_v2_run01

팀 검토 후 실행합니다. OpenAI 임베딩 API 호출 비용과 DB 조회가 발생합니다. 출력 폴더는 실행마다 새 이름을 사용합니다. 이 명령은 이전 대화·의도 판단·최종 답변을 평가하지 않습니다.
