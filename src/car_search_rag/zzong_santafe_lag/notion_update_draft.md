# 1차 프로젝트 — 실제 구현 변경 및 검토 기록 초안

2026-10-06 작성. 아래 문안을 초기 계획에 '실제 구현과 변경 이유' 항목으로 추가할 수 있습니다. 이번 작업에서 노션 본문을 새로 읽거나 요구사항 충족 여부를 다시 판정한 기록은 아닙니다. 기존 대화의 결정과 현재 개인 코드를 기준으로 작성했습니다.

## 실제 구현 방향

싼타페 HEV PDF 설명서 한 개를 근거로 출처와 관련 그림을 함께 보여주는 RAG 챗봇을 구현했습니다. 외부 차량 정보 수집·웹 검색·현재 리콜 대상 조회·개별 차량 고장 진단은 구현 범위에서 제외합니다. PDF에 없거나 검토되지 않은 자료는 확정 답변을 보류합니다.

## 청킹과 검색

주제별 부모 기록에 전체 본문과 경고·주의사항을 보관하고, 작은 자식 청크로 검색합니다. 관련 자식을 찾으면 부모와 필요한 각주·주의사항을 다시 연결합니다. 그림은 소제목 문맥에 연결하고 확인한 그림 설명도 검색용 글에 넣습니다. 같은 페이지라는 이유만으로 모든 그림을 한 주제에 붙이지 않도록 검토합니다.

검색은 OpenAI 임베딩·글자 TF-IDF·질문 목적·구체 표현을 결합한 자체 검색 서비스입니다. LangChain BaseRetriever나 RetrievalQA 구현으로 표시하지 않습니다. 질문 처리 목적 규칙은 검색 범위와 답변 근거 선택에서 공유합니다.

## 모델과 답변

- 기본 임베딩: LangChain OpenAIEmbeddings의 `text-embedding-3-small`, 1536차원.
- 비교용 로컬 임베딩: `jhgan/ko-sroberta-multitask-mrl`, 768차원. 같은 공간의 문서·질문만 비교합니다.
- 답변: LangChain ChatOpenAI의 `gpt-6-luna`. 확인한 PDF 근거만 정리하고 출처 번호를 검사합니다.
- 그림: 실제 Storage 파일 표시. 이미지 픽셀 임베딩과 멀티모달 모델의 그림 해석은 구현하지 않았습니다.

프롬프트·출력·인용 형식 검사가 모든 문장의 의미 정확도를 보장하지는 않습니다. 원문 발췌와 생성 답변, 검색 성공과 근거 선택 성공을 구분해 기록합니다.

## 저장과 팀 작업

개인 코드 폴더 `src/car_search_rag/zzong_santafe_lag`, 개인 Supabase 스키마 `zzong_santafe_lag`를 사용합니다. 부모·청크·그림 파일·연결·처리 버전을 구별하고 원문을 보존합니다. 기존 모델 벡터와 새 모델 벡터는 별도 테이블로 보관합니다.

검토 보완 자료는 별도 수정 버전으로 보관해 원본 부모·벡터를 덮어쓰지 않습니다. 기존 그림 파일을 재사용하고 일부 수정 청크만 재임베딩해 추가 용량을 줄입니다. 다른 팀원 코드·공통 설정·다른 스키마의 자료를 변경하지 않습니다.

## 평가와 남은 범위

초기 샘플·같은 30문항 모델 비교·새 표현 평가·화면 조건 확인을 단계별로 기록했습니다. 새 평가에서 그림 번호와 조절 시점 질문을 잘못 분류한 사례를 발견해 보완했습니다. 기존 질문으로 보완 후 확인한 수치는 회귀 확인이며 독립 평가로 표시하지 않습니다.

Precision@5는 후보의 실제 내용으로 판정합니다. 사람 교차 검토 전 Codex 판정과 경계 사례를 남깁니다. 요구사항에 Precision@K가 필수라고 확인했다는 주장은 하지 않습니다.

전체 자료 저장과 전체 자료의 원문 검토 완료는 다릅니다. 실외 미러·스마트 테일게이트의 부모 5개·수정 청크 28개·그림 연결 8개를 개인 DB의 별도 버전으로 저장했습니다. 적용한 검색 자료는 검토 부모 25개, 남은 초안 502개이며 검색용 청크는 2,216개입니다. 원본 개인 8개 테이블은 내용 식별값으로 보존을 확인했습니다.

저장 전 회귀 확인은 18/18, 저장 후 실제 DB 근거 조회는 3/3입니다. 테일게이트 생성의 필수 출처 누락 사례를 보존하고 프롬프트 보완 후 같은 근거로 재확인했습니다. 이 결과를 독립 질문의 전체 답변 정확도로 표시하지 않습니다. 사람 교차 검토·추가 독립 질문·미검토 자료 확인이 남아 있습니다.

세부 실행 수치와 DB 반영 여부는 [최신 확인 안내](./sequence_completion_guide.md)와 최종 결과 요약 파일에 기록합니다.
