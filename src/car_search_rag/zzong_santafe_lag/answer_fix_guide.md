# 답변 근거 선택·생성 검사 보완 결과 — 2026-10-05

## 무엇을 고쳤나요?

사용자 확인을 받고 개인 싼타페 코드의 두 부분을 수정했습니다.

1. **질문에 맞는 자료 선택:** 조작 방법·허용 여부 질문에는 위치 안내도만으로 답하지 않고, 지시 문장이 있는 검토된 자료를 우선 선택합니다. 같은 조건에서는 질문 단어가 더 많이 일치하는 자료를 고르고 동점은 검색 순서를 유지합니다. 위치·일반 사실 질문은 원래 검색 순서를 유지합니다.
2. **생성 검사 사유 기록:** 생성 글과 검사 결과를 개인 결과 JSON에 남깁니다. JSON 형식, 답변 보류 항목, 없는 출처 번호, 필수 출처 누락, 출력 한도 등을 구별합니다. 외부 오류 문장·키·인증 헤더를 기록하지 않습니다.

추가 진단에서 연료 답변이 실패한 실제 이유는 **질문과 무관한 오일 각주 출처를 인용하지 않았기 때문**으로 확인됐습니다. 이번 진단의 모델 원문에는 `67 ℓ·무연 휘발유`와 표 출처 [1]이 있었지만, 검사에서 각주 출처 [2]까지 강제했습니다. 이전 평가 당시에는 상세 기록이 없으므로 이전 실패 원인까지 확정한 것으로 표현하지 않습니다.

그래서 검토된 표에서 질문에 명시한 항목에 각주 번호가 없는 경우에만 연결 각주를 참고 자료로 표시합니다. **표 본문은 필수**, 엔진 오일·브레이크액 등 **해당 항목의 각주가 있으면 연결 각주도 필수**입니다. 전체 표·주의·각주 질문이나 항목을 명확히 찾지 못한 경우는 기존 필수 인용을 유지합니다. 복합 질문 중 한 항목에서 필수인 자료는 전체에서도 필수입니다.

참고 자료의 원문·주의사항은 모델 입력과 결과에 그대로 남습니다. 질문에 관련된 주의는 여전히 답변하도록 지시합니다. 없는 출처를 인용하거나 필수 출처를 빠뜨리면 발췌로 돌아갑니다. 오래된 노트북의 필수 여부 표시가 없는 근거도 기존처럼 모두 필수입니다.

이 규칙은 이번 PDF와 한국어 표현에 대한 제한된 보완입니다. 모든 질문의 의미를 정확히 이해하는 분류기나 답변의 의미 정확도 검사로 보지는 않습니다.

검색 순위·청크·벡터를 바꾸지 않고 새 질문 10개 × 두 모델의 **저장된 검색 20건**을 재사용했습니다.

- 기존 업로드 후 v2 기대 조건을 바꾸지 않고 10문항을 새로 검색했습니다. **10/10 조건 일치**: 위치·표·복합 질문·그림 연결 유지, 리콜/실제 고장 질문은 PDF 밖 보류, 미검토 스마트 테일게이트는 생성 보류입니다. 그림 참조의 연결 검사이며 이번에 브라우저 그림 픽셀을 다시 확인한 것은 아닙니다.
