## 노트북에서 Python 파일로 바뀌는 점

노트북은 셀을 하나씩 실행하면서 결과를 확인하는 실험 기록입니다. Python 파일은 확인한 작업을 함수로 묶어 같은 순서로 다시 실행하는 프로그램입니다.

예를 들어 노트북의 “PDF 읽기” 셀은 `pdf_reader.py`의 `inspect_pdf()` 함수가 되었습니다. 함수는 입력을 받아 정해진 일을 한 뒤 결과를 돌려주는 작은 작업 묶음입니다.

**처리 순서:** PDF 읽기 → 주제별 원문 묶기 → 확인한 표 보완 → 작은 청크 만들기 → 임베딩 → 근거 검색.

전체 원문 묶음을 **부모 기록**, 검색하기 좋은 작은 조각을 **자식 청크**라고 부릅니다. 작은 청크로 찾은 뒤 답변에 필요한 원문·각주·주의사항은 부모 기록에서 읽습니다.

## 읽어 볼 파일 순서

| 파일 | 역할 |
| --- | --- |
| `manual.py` | 시작 파일. 미리보기·검색·기존 질문 비교 중 무엇을 할지 받습니다. |
| `manual_service.py` | 위 처리 순서대로 함수를 호출합니다. 먼저 `prepare()`를 읽습니다. |
| `config.py` | PDF 경로와 모델·CPU 설정입니다. |
| `pdf_reader.py` | 페이지 글자, 목차, 인쇄 쪽수, 이미지 키를 읽습니다. |
| `sample_records.py` | 노트북에서 확인한 안내도와 본문 예제를 재현합니다. |
| `topics.py` | 목차 제목과 인쇄 쪽수로 전체 본문을 자동 주제 초안으로 묶습니다. |
| `reviews.py` | 화면에서 대조한 오일 표·패들 기호·각주 관계를 보완합니다. |
| `chunking.py` | 실제 토큰 한도 안으로 나눕니다. 확인한 표는 행 관계를 유지합니다. |
| `embedding.py` | 설치된 한국어 모델로 청크를 768개 숫자로 바꿉니다. |
| `retrieval.py` | 의미 점수와 글자 점수를 결합하고 질문 목적에 맞는 자료를 찾습니다. |
| `evaluation.py` | 기존 30개 질문의 기대 출처와 검색 결과를 비교합니다. |
| `source_review.md` | 이번에 검토한 안전벨트 질문의 원본 근거와 남은 문제입니다. |

한 번에 모든 파일을 이해할 필요는 없습니다. 첫 실행 결과를 확인한 다음 `manual.py → manual_service.py → pdf_reader.py` 순서로 살펴보면 됩니다. 각 함수와 중요한 처리에 한국어 설명을 달았습니다.

## 검색 실험

```powershell
.\.venv\Scripts\python.exe .\src\car_search_rag\zzong_santafe_lag\manual.py search --question "엔진 오일의 용량과 추천 사양을 알려줘."
```

처음에 전체 2,213개 청크를 CPU에서 임베딩하므로 시간이 걸립니다. 진행 개수와 예상 남은 시간을 표시합니다. 모델은 이미 다운로드한 `jhgan/ko-sroberta-multitask-mrl`을 로컬에서 읽습니다. 모델 캐시가 없으면 다운로드를 시도하지 않고 오류로 중단합니다.

같은 실행에서 여러 질문을 비교하려면 `--question`을 반복합니다. 청크 임베딩을 한 번만 계산합니다.

```powershell
.\.venv\Scripts\python.exe .\src\car_search_rag\zzong_santafe_lag\manual.py search --question "안전벨트 버클을 얼마나 밀어 넣어야 하나요?" --question "차단 클립을 버클에 꽂으면 경고등과 경고음은 어떻게 되나요?"
```

표시되는 내용은 **검색 후보**입니다. 높은 점수는 정답 보장이 아닙니다. PDF 쪽수, 원문, 검토 상태를 함께 확인합니다. `--full-text`를 붙이면 연결 원문 전체를 표시합니다.

이미지는 페이지 번호와 이미지 키·설명·기존 로컬 경로를 연결합니다. 이 명령은 이미지를 새로 저장하거나 화면에 그림 자체를 표시하지 않습니다. 전체 864개 그림의 설명이 완성된 상태도 아닙니다. 자동 추출된 그림 연결은 페이지 수준 초안으로 표시합니다.

DBeaver에서는 `.sql.txt`의 내용을 SQL 편집기에 가져와 사용합니다.
