# 안전벨트 검색 후보의 원본 근거 검토

검토일: 2026-10-01. 실제 PDF 54쪽과 110쪽 전체 화면을 텍스트 추출 결과와 대조했습니다. PDF 105~112쪽 및 227쪽의 추출 글도 확인했습니다.

## 1. 버클을 얼마나 밀어 넣어야 하나요?

| 근거 | 내용 | 판단 |
| --- | --- | --- |
| PDF 54 / 매뉴얼 49 | “찰칵” 소리가 날 때까지 버클에 밀어 넣으라는 문장 | 기존 평가에서 정한 `seatbelt_54` 근거 |
| PDF 110 / 매뉴얼 105 | “찰칵” 소리가 날 때까지 플레이트를 버클에 밀어 넣고, 손으로 세게 당겨 잘 채워졌는지 확인하라는 문장 | 질문에 답할 수 있는 다른 유효한 근거 |

따라서 PDF 105~112를 포함한 자동 주제가 검색됐다는 이유만으로 첫 질문의 근거가 틀렸다고 판단할 수는 없습니다. 실제 해당 문장을 읽어야 합니다.

다만 110쪽을 확인했다고 105~112쪽 전체 원문 묶음과 모든 그림을 확인한 것은 아닙니다. 해당 자동 주제의 `auto_draft_needs_review` 상태는 유지했습니다. 30문항의 기대 출처 목록도 결과를 본 뒤 바꾸지 않았습니다. 향후 평가 개선에서는 처음부터 복수의 유효한 근거를 등록하고 새 평가 버전으로 비교할 수 있습니다.

## 2. 차단 클립을 버클에 꽂으면 어떻게 되나요?

PDF 54 / 매뉴얼 49에 다음 관계가 명시되어 있습니다.

- 차단 클립을 꽂으면 안전벨트를 착용한 것으로 인식합니다.
- 그 결과 안전벨트 미착용 경고등 및 경고음이 작동하지 않습니다.
- 같은 경고 구간에 안전벨트의 정상적인 착용과 사용을 방해하는 물품을 사용하지 말라는 지시가 있습니다.

PDF 227쪽 “경보 상태”는 도난 경보 관련 자료입니다. 안전벨트 차단 클립에 대한 답변 근거로 사용할 수 없습니다.

이번에 확인한 PDF 105~112쪽 추출 글에서는 “차단 클립” 문구를 찾지 못했습니다. 이 확인을 PDF 전체에 같은 내용이 없다는 주장으로 확대하지 않습니다.

## 3. 이번 변경 범위와 남은 작업

이번 Python 정리는 노트북 12번의 청킹·임베딩·검색 방식을 재현합니다. 특정 평가 질문의 정답 ID를 검색 규칙에 넣지 않았습니다. 따라서 파일 형식을 바꾸는 것으로 차단 클립 검색 문제가 해결됐다고 판단하면 안 됩니다.

다음 검색 개선에서는 안전벨트 주제의 세부 경계와 검색용 문맥을 검토하고, 비슷한 표현을 사용하는 도난 경보 자료와 구별되는지 비교해야 합니다. 버클 관련 다른 유효한 근거는 별도 근거 판정으로 기록합니다.

현재 검색 후보에는 미검토 초안도 포함됩니다. 근거를 확인하지 않고 후보 점수만으로 답변하는 기능은 아직 구현하지 않았습니다. 이미지 자체의 임베딩이나 전체 그림 OCR도 완료되지 않았습니다.
