# 통계 검정 계획서

## 현재 상태

현재 저장소에서 검색 개선 전·후 질의 결과를 대상으로 하는 통계 검정 코드나 실행 결과를 확인하지 못했다. 아래는 향후 평가 데이터를 확보한 뒤 수행할 계획이며, 실제 검정 결과가 아니다. p-value와 유의성 결론은 아직 없다.

## 비교 설계

- **비교 대상:** 핵심 `car_search`의 baseline 검색과 변경 검색.
- **표본 단위:** 양쪽 검색 설정에 모두 실행한 동일 질의 한 건.
- **고정 조건:** PDF corpus·평가 질의·기대 근거 ID·top-k·평가 구현을 동일하게 유지한다.
- **지표:** 첫 관련 결과의 reciprocal rank (RR = 1/rank, top-k 밖이면 0), top-k 성공 여부(성공 1/실패 0), 필요하면 관련 문서의 순위.

## 가설과 검정

### 주 지표: Reciprocal Rank

- 귀무가설 H0: paired query의 baseline과 변경 후 reciprocal rank 차이의 모집단 중앙 위치/평균은 0이다.
- 대립가설 H1: 변경 후 reciprocal rank가 baseline보다 크다.
- 검정: 동일 질의별 RR 차이에 대한 **Wilcoxon signed-rank 검정**, 양측 유의수준 0.05를 기본 계획으로 한다. 방향성 가설을 사전 명시하고 방법론 요구가 단측 검정을 허용할 때만 단측 여부를 평가 전에 고정한다.
- 선택 이유: RR은 순위가 좋아질수록 커지는 paired 측정값이다. 소규모 평가셋의 차이 분포가 정규라고 확인되지 않은 상황에서 비모수 paired 검정을 우선 계획한다. 차이값의 대칭성 가정도 점검하고, 부적절하면 사전에 정한 대안으로 전환한다.

### 보조 지표: top-k 성공 여부

- 귀무가설 H0: baseline과 변경 후 top-k 성공 여부의 쌍에서 성공/실패 전이 확률이 같다.
- 대립가설 H1: 변경 후 성공 전이와 악화 전이 확률이 다르다 (또는 사전 정의 시 변경 후 성공이 더 많다).
- 검정: **McNemar 검정**을 paired binary outcome에 적용한다. 불일치 쌍 수가 적으면 exact McNemar 검정을 사용한다.
- 선택 이유: 같은 질의에서 두 설정의 hit 여부를 비교하는 이진 paired 데이터이기 때문이다.

### 검색 순위

검색 순위 자체를 비교하려면 각 질의의 첫 관련 순위를 기록한다. 상위 k 내 순위는 RR 또는 사전 정의한 순위 점수로 변환해 paired 비교한다. 순위 숫자만 단순 평균 내는 분석은 순위 분포와 top-k 밖 처리 규칙을 먼저 정의하지 않으면 사용하지 않는다.

## 보고할 항목

평가 질의 수, top-k, 검색 corpus와 revision, 지표 정의, 양쪽 점수 요약, paired 차이, 검정명, 유의수준, p-value, 효과 크기 및 신뢰구간을 함께 보고한다. 반복 질의·동일 차량 문서의 상관성이 결과에 미치는 한계도 기록한다.

## 실행 결과

**실제 통계 검정 실행 결과 없음. p-value 없음. 유의성 결론 없음.** 이 계획서 작성 과정에서는 검정을 실행하지 않았다.
