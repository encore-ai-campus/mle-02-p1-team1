# M7 개선 실험 After 평가

> 본 문서는 M6 Before baseline을 보존하고 M7 변경 및 After 결과를 별도로 기록한다. 브라우저 E2E 결과와 공식 Retrieval-only 평가는 다른 측정이다.

## 범위와 변경

- 대상: Hyundai Sonata 2026 (`car_id=20261004_000017`)
- 현재 데이터: chunk 947, image 955, `image_desc` NOT NULL 890 / NULL 65 (coverage 93.2%)
- 기존 M6 baseline: 11문항, Hit@5 9/11 (81.8%), MRR@5 0.5333. M6 결과 파일은 수정하지 않았다.
- 기존 chunk retrieval 경로는 `image_desc`를 사용하지 않았다. M7에서는 기존 텍스트 검색 SQL, embedding, Top-k, 답변 prompt를 유지하고, 검색된 Top-10 page 범위 안에서만 image_desc를 읽어 이미지 표시 순서를 별도로 선택하도록 추가했다.

## image_desc 개선 과정

초기 EDA는 이미지 955건 전부 `image_desc` NULL(100%)이었다. 주변 문맥 deterministic 규칙을 production에 처음 적용했을 때 9/955(0.94%)만 채워졌다. Text LLM 비교는 동일 seed 20261004의 100건 표본에서 gpt-4.1-mini 7건 통과/50건 fallback, gpt-5.6-luna 44건 통과(기존 문구와 동일 37, 실제 변경 7), gpt-5.6-terra 39건 통과(실제 변경 9, 명확한 가독성 개선 3)였다. 후보 자체의 한계 때문에 production 생성에서는 LLM을 쓰지 않기로 했다.

주변 context 확장 실험은 동일 100건에서 명확한 개선 사례를 3건에서 25건으로 늘렸으나 다른 이미지/주제 문맥 혼입, 필요한 문맥 누락, 요약 중 정보 손실이 확인됐다. 이후 PDF heading/layout 분석에서 이미지 위쪽·같은 column·수평 겹침·상대 거리와 실제 문서 제목을 이용하는 deterministic extraction을 설계했다. 제목 100건 표본에서 35건을 추출했고, 정상 제목에도 9pt가 쓰여 font size만으로 판단하면 누락되는 사례를 확인했다.

최종 등록 방식은 PDF에 실제 있는 제목/기능명/절차명과 필요한 A/B label만 조합하며 새 설명을 생성하지 않는다. 최종 현재 결과는 heading only 400, heading+label 490, NULL 65로 총 890/955(93.2%)이다. image_desc는 완전한 caption이 아닌 이미지 검색 metadata이며 개별 사람이 890건 전체를 검수한 것은 아니다. DB에 저장됐다는 사실만으로 RAG 검색 품질이 개선되는 것은 아니며, 실제 선택/검색 활용과 관련성 평가가 별도 필요하다.

현재 UI에서 이미지 preview 25개가 DOM 상 complete 상태이고 이미지 크기를 읽을 수 있었다. 원본 이미지 링크는 모든 preview에 clickable anchor로 표시됐다. M6-11 p468 링크를 직접 클릭해 새 탭에서 `page_0468_image_02.png` (457×292) 원본이 열린 것을 확인한 뒤 앱 탭으로 복귀했다. 몇 preview는 실제 표시 크기가 매우 작아 보이는 예외가 있었고, 이미지 선택은 여전히 질문과 의미가 약하게만 연결된 결과를 포함했다.

## UI 평가 해석 및 남은 개선 후보

- 이미지 선택 metadata를 사용한 M7 코드는 이미지 표시만 조정한다. 공식 chunk Hit@5/MRR@5 개선은 이번에 관찰되지 않았다.
- 이미지 relevance 후보: M6-03의 주차 경고 이미지, M6-05의 타이어 교체 이미지, M6-06의 오일 압력 경고 그림, M6-08의 타이어 위치 교환 그림, M6-09의 위치 교환 그림.
- 브라우저 실행과 retrieval-only 결과가 달라 보이는 M6-02, M6-03은 같은 설정/질문으로 반복 재현하며 UI에 전달되는 검색 결과와 답변 근거 결합을 확인한다.
- 공식 M7 After text retrieval 점수는 M6와 같은 수치다. 브라우저 시연은 official Hit@5/MRR@5가 아니다.
- 8501 서버는 사용자의 명시적 재시작 후 같은 포트에서 확인했다. 앱에서 11개 문답은 정상 완료됐다.
