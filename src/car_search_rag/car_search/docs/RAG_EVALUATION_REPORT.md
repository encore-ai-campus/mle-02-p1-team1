# RAG 검색 품질 평가 보고서

## 평가 범위

핵심 평가 대상은 data/DN8_2026_ko_KR.pdf와 hyundai / sonata / 2026 조건으로 검색하는 car_search 서비스다. 이 보고서에는 소나타 기준으로 확인 가능한 평가 자산과 결과만 기록한다.

## 소나타 평가셋

소나타 PDF의 기대 근거 ID가 연결된 검색 질의 평가 데이터셋은 현재 확인되지 않았다. 따라서 질의 수와 평가셋 구성 결과는 현재 미확인이다.

## 핵심 car_search 평가 코드

CarManualSearchService.search_manual은 query embedding을 만들고 저장소 검색을 호출한다. SQL search_car_manual은 차량 제조사·차종·연식을 조건으로 필터링하고 pgvector <=> 거리를 기준으로 정렬한 뒤 limit을 적용한다. 서비스 기본 limit은 5이며 app_kbj.py의 호출은 10이다.

소나타에 대한 Hit@k, MRR@k, reciprocal rank 또는 검색 순위 평가를 실행하고 저장한 결과는 확인되지 않았다.

**소나타 기준 검색 품질 평가 결과 없음.**

## 개선 전·후 비교

소나타 동일 평가 질의를 사용한 검색 개선 전·후 비교 실행 결과는 없다. Baseline → 개선 → 동일 질의 재평가 순으로 수행하고, 동일 데이터·정답 근거·top-k 조건을 유지해 결과를 기록해야 한다.

## 추가 실행 필요

1. 소나타 매뉴얼만 대상으로 정답 근거가 확인된 평가 질의를 만든다.
2. 현행 검색 설정의 baseline Hit@k·MRR 결과를 저장한다.
3. 변경 후 동일 질의와 동일 조건으로 다시 평가한다.
4. 질의별 결과와 집계 지표를 함께 보관한다.

이 문서 작성 단계에서는 평가를 실행하지 않았다.
