# M6 공식 Retrieval-only 평가 결과

> 공식 baseline (M7 Before). 본 결과는 브라우저 E2E 및 Chat API 답변 평가와 구분한다. LLM 답변 생성은 실행하지 않았다.

## 실행 조건 및 범위

- 기준: Notion M6 질문셋 M6-01~M6-11 및 기대 근거를 그대로 사용.
- 차량: Hyundai Sonata 2026, `car_id=20261003_000014` 한 대 (검색 조건 `hyundai / sonata / 2026`의 사전 확인 결과도 이 차량 한 건).
- 독립 경로: 원 질문 → `text-embedding-3-small` → 기존 `CarManualSearchService.search_manual()` / `CarManualRepository.search_manual()` → `search_car_manual` pgvector cosine 거리 Top-10 조회. LLM/Chat API, 대화 이력, Streamlit은 사용하지 않았다.
- 공식 Hit@5와 MRR@5는 Top-5만으로 계산했다. Top-10은 실패 위치를 분석하기 위해 함께 읽었다.
- 데이터베이스는 읽기 전용 SELECT만 사용했다. 차량 filter 적중 ID 1개, Sonata chunk 947개 확인. 다른 차량은 사용하지 않았다.
- 평가 중 검색 SQL, embedding, chunking, prompt 및 DB를 수정하지 않았다.

## overlap 인접 chunk 검토

chunk_overlap=150인 기존 DB 텍스트를 확인했다. 단순히 번호가 인접한다는 이유로 인정하지 않고 동일한 질문 근거가 인접 텍스트 안에 실제로 반복된 경우에만 acceptable로 추가했다. 적용한 인접 근거: M6-04 p.115/c223 (잠금 후 손잡이를 당겨 확인하는 단계 반복), M6-06 p.463/c867 (게이지 닦기·재삽입 후 뽑기), M6-09 p.479/c893 (교체 깊이 기준 연속 문장). 그 밖의 adjacent chunks는 같은 질문의 정답 근거를 담지 않아 제외했다.

## 전체 지표

| 평가 방식 | Hit@5 | MRR@5 |
|---|---:|---:|
| 브라우저 E2E 관찰 | 5/11 (45.5%) | 참고값 (산출하지 않음) |
| 공식 Retrieval-only | 9/11 (81.8%) | 0.5333 |

공식 Retrieval-only는 브라우저에서 관찰한 출처 표시와 달리 매 질문을 독립 검색한 Top-5 결과로 계산했다. 이번 한 번의 run 결과이며 실행 간 변동성은 이번 평가에서 재측정하지 않았다. 브라우저 Hit@5보다 공식 결과가 4문항 높게 나왔지만, 이는 화면 UI 표기 측정과 독립 Retrieval 검색이라는 경로 차이가 있으므로 동일 점수로 비교할 수 없다.

### 원인 분류 요약

- 확인된 직접 원인은 두 문항 모두 B: 기대 근거가 Top-5 cutoff 밖에 있었다.
- M6-05와 M6-11은 정답 chunk가 Top-10에는 존재하므로 완전 미검색보다는 순위화/상위 결과 경쟁 문제 후보다. embedding 자체의 결함, 질문 표현 차이, chunk 분할 또는 SQL 필터 오류라고 확정할 증거는 이번 단일 검색 결과만으로 충분하지 않다.
- 검색 필터는 Sonata ID 하나에 매핑됐으므로 F(검색 조건/차량 필터 문제)는 관찰되지 않았다. 허용 adjacent evidence를 검사했으나 두 FAIL의 Top-5 안에 같은 근거의 인접 chunk는 없었다 (C 아님).
- G (정답셋 정의 문제)를 입증할 자료도 없었다. 정답 위치는 Notion 기준을 유지했다.

## 판정 및 M7 Before

- 공식 Hit@5: **9/11 (81.8%)**. PASS: M6-01, M6-02, M6-03, M6-04, M6-06, M6-07, M6-08, M6-09, M6-10.
- 공식 MRR@5: **0.5333**.
- FAIL: M6-05, M6-11. 정답은 각각 rank 6, rank 10에 확인됐다.
- 가장 큰 개선 후보: 상위 5개 순위의 relevance. 특히 M6-05는 와이퍼 교체 판단 근거가 rank 6, M6-11은 브레이크액 MIN 조치가 rank 10이었다.
