# SONATA Synthetic Holdout 50문항 UI 평가

- 평가 질문 원본: `src/car_search_rag/car_search/docs/UNSEEN_50_QUESTION_SET_20261004.csv` (U50-001~U50-050)
- 실행 방식: 실행 중인 Streamlit 통합 앱의 visible browser에서 SONATA를 선택해 문항별 입력·응답·출처·inline 이미지를 확인
- page/chunk 제한: UI Top-5에는 PDF page만 표시되고 chunk 번호는 노출되지 않았다. 따라서 아래 랭크와 지표는 기대 page 기준이다. chunk 기준 일치 여부는 검증 불가.
- 세션 조건: U50-001~035와 U50-036~050은 세션 중단 후 이어서 실행한 연속 평가 결과. 하나의 uninterrupted 50문항 실행이 아니며, 공식 UI4와 동일 조건 비교가 아니다.
- 변경 사항: 코드 및 RAG 설정 수정 없음. commit/push 없음.
