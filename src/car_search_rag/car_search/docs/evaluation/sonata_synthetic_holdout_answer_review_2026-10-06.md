### 상세 기록 항목 설명

- **질문**
  평가에 사용한 원본 사용자 질문.

- **기대 근거**
  평가 전에 사람이 정한 Gold Evidence 위치.
  PDF page와 chunk 번호로 기록한다.
  검색 결과를 보고 사후에 변경하는 값이 아니다.

- **실제 챗봇 답변**
  Streamlit SONATA UI에서 실제 사용자에게 표시된 최종 답변.
  사람이 기대 답변과 비교하여 정답 여부를 판단하는 대상이다.

- **출처**
  실제 챗봇 화면에 표시된 매뉴얼 근거 및 검색 출처.
  답변이 어떤 매뉴얼 내용을 근거로 생성됐는지 확인하기 위한 항목이다.

- **검색 결과**
  RAG의 Top-5 검색 결과와 기대 근거의 검색 순위를 기록한다.

  - Expected page rank:
    기대 근거가 Top-5 중 처음 등장한 순위
  - Retrieval HIT:
    기대 근거가 Top-5에 포함됨
  - Retrieval MISS:
    기대 근거가 Top-5에 포함되지 않음

  Retrieval MISS는 최종 답변이 오답이라는 뜻이 아니다.

- **UI**
  실제 서비스 실행 상태.
  latency, inline image 수, timeout, exception 등을 기록한다.

- **답변 출처**
  답변 내용의 근거가 아니라,
  현재 기록된 답변 원문을 어느 실행에서 확보했는지 나타낸다.

  예:
  - 기존 평가 답변 원문에서 복구
  - 답변 검토용 재실행

- **사람 검토**
  사람이 Golden/Expected Answer와 실제 답변을 비교하여 최종 판정한다.

  - 정답: 핵심 내용이 정확하고 중요한 누락 없음
  - 부분 정답: 핵심 일부는 맞지만 중요한 내용이 누락됨
  - 오답: 핵심 사실이 틀렸거나 질문과 다른 답변
  - 다른 유효 근거로 정답:
    Gold page/chunk는 검색하지 못했지만 다른 유효한 매뉴얼 근거로 정확히 답함
  - 판단 보류:
    추가 확인이 필요한 경우

- **메모**
  자동 지표로 표현하기 어려운 특이사항을 사람이 기록한다.

### 평가 개념 구분

- Retrieval 평가
  → 정답 근거를 검색했는가
  → Hit@K, MRR

- Answer 평가
  → 최종 답변이 실제로 맞는가
  → 정답 / 부분 정답 / 오답

- Grounding 평가
  → 답변이 실제 매뉴얼 근거로 뒷받침되는가

따라서:

`Retrieval MISS ≠ Answer 오답`
