# TF-IDF 분석: 소나타 2026 DB Chunk

## 분석 범위와 방법
PostgreSQL의 현재 RAG 적재 데이터 중 CAR_BRAND_ENG_NM='hyundai', CAR_ENG_NM='sonata', CAR_MODEL_YR=2026에 해당하는 차량만 대상으로 했다. 조회한 CAR_ID는 20261003_000014이며, 이 차량의 CAR_MANUAL_CHUNK 본문을 그대로 corpus로 사용했다. PDF를 재처리하거나 임시 chunk를 만들지 않았다. DB 조회는 DB_URL 접속 후 SELECT만 수행했다. Embedding baseline은 CarManualSearchService.search_manual → CarManualRepository.search_manual → car_manual.sql의 search_car_manual 경로를 호출했다. 질문 embedding 모델은 CarManualSearchService의 text-embedding-3-small이며, pgvector cosine distance(<=>)로 정렬하고 1-distance를 similarity로 반환한다. 답변 생성은 하지 않았고 DB 비밀값은 출력하지 않았다.

한글 형태소 분석기 없이 문자열 조각 일치를 다루고, 저장 텍스트의 띄어쓰기·줄바꿈 변동에 일부 대응하도록 문자 n-gram을 선택했다. 의미 유사성은 학습하지 않으므로 표현이 달라지는 질문에 취약할 수 있다.

## 관찰과 한계
엔진오일 질문은 TF-IDF 2위, embedding 2위에서 근거를 찾았다. 후드 질문은 TF-IDF가 p.164/chunk 317을 top-5에서 찾지 못했으나 embedding은 4위에 반환했다. 배터리 질문은 양쪽 모두 1위에서 p.475/chunk 885를 찾았다. 이 세 질의에서는 TF-IDF가 2개, embedding이 3개 근거를 top-5에 포함했다. 이는 소규모 예시이며 전체 검색 품질, 개선 전후 성능, 통계적 유의성을 뜻하지 않는다. 문자 n-gram은 형태소·의미를 이해하지 않으며 추출 텍스트의 공백·줄바꿈 영향을 받는다. 답변 생성 정확도도 평가하지 않았다.

## 결론
실제 DB의 소나타 2026 chunk 947건을 corpus로 분석했다. 동일 세 질문에서 엔진오일과 배터리 근거는 양쪽이 찾았고, 후드 근거는 TF-IDF가 놓쳤으며 pgvector는 top-5에 포함했다. 실행 노트북은 notebooks/sonata_tfidf_analysis.ipynb이다. TF-IDF는 분석용이며 서비스에 추가하지 않았다.
