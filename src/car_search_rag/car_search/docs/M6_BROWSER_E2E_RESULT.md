- URL: http://localhost:8501/

## 요약 및 실패 유형

- 기대 근거가 출처 Top-5에 관찰된 질문: M6-03 (5위), M6-07 (5위), M6-08 (3위), M6-09 (1위), M6-11 (5위) — 5/11.
- 기대 근거 미표시: M6-01, M6-02, M6-04, M6-05, M6-06, M6-10 — 6/11.
- 답변 생성은 11/11. M6-04, M6-10은 출처가 없는 근거 부족/보류 응답이었다.
- 관련성 실패 후보: M6-02의 이질적 검색 이미지, M6-08의 p.29 냉각수 이미지, M6-11의 p.464 엔진오일 이미지. 화면상 이미지가 현재 검색 page의 이미지인지, 직전 질문 metadata 혼합인지 완전히 판별할 수 없어 후속 검색/렌더 경로에서 확인이 필요하다.
- 출처 metadata가 없는 질문(M6-01/04/06/10)은 화면에서 Top-5를 확인할 수 없어 브라우저 관찰 기준 not found로 기록했다. 이는 공식 SQL Top-5 직접 측정 결과가 아니다.
- 같은 채팅의 질문/답변은 각각 표시됐고 눈에 띄는 겹침·잘림·오류는 없었다. 질문 사이에 이전 출처가 다음 답변에 복사된 현상은 확인되지 않았다. 다만 M6-11의 무관한 이미지 하나는 이미지 연관성 또는 metadata 연결 오류 후보로 남긴다.

## 공식 평가와 구분

이 문서는 실제 브라우저에 렌더링된 답변·출처·이미지를 관찰한 기록이다. 공식 Retrieval-only 평가는 각 질문의 query embedding과 pgvector Top-5를 독립적으로 실행해 산출해야 한다. 공식 Hit@5/MRR@5와 이 브라우저 관찰값은 실행 경로와 측정 대상이 다르므로 별도 보고한다.
