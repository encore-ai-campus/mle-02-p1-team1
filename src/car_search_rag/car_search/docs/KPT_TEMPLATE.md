# KPT 회고 작성 후보

아래는 소나타 핵심 프로젝트 코드에서 확인되는 기술 사실을 바탕으로 한 선택 후보이며 개인 회고 완성본은 아니다. 작성자가 실제 경험에 맞는 항목을 선택하고 문장을 직접 수정한다.

## Keep

- [후보] 등록 흐름을 PDF 읽기, chapter 추출, chunk 분할, embedding, DB 저장 메서드로 나눈 구조를 유지할 수 있다.
- [후보] 검색 결과를 페이지 번호 및 chapter 정보와 연결해 근거 위치를 반환하는 구조를 유지할 수 있다.
- [후보] 대화 이력을 검색 질문 재작성과 답변 생성에 전달하는 흐름을 유지할 수 있다.

## Problem

- [후보] 소나타 PDF의 페이지별 텍스트 통계, 빈 페이지, chunk 길이 분포를 측정한 결과가 아직 없다.
- [후보] PDF 및 chunk 중복 등록을 식별하는 hash 기반 정책이 핵심 경로에서 확인되지 않는다.
- [후보] 소나타 평가셋, 검색 품질 결과 및 통계 검정 결과가 아직 없다.
- [후보] 핵심 Streamlit 앱의 시연 성공 기록을 확인할 수 없다.

## Try

- [후보] 소나타 PDF에 대한 재현 가능한 페이지·텍스트·chunk EDA를 수행한다.
- [후보] 소나타 정답 근거 검색 질의셋을 만들고 baseline을 기록한다.
- [후보] 같은 소나타 질의의 baseline/변경 후 순위 지표를 paired 검정한다.
- [후보] 핵심 Streamlit 앱의 소나타 검색·답변 경로를 시연하고 결과를 남긴다.
