# 개인 싼타페 코드의 학습 기록 규칙

이 폴더와 관련 개인 노트북의 작업에서는 사용자가 요청한 한국어 설명과 추가 적용 기록을 유지한다.

- 새 모델·라이브러리 사용·처리 규칙·실험 설정을 적용하면 해당 코드 옆에 한국어 주석으로 이유, 역할, 적용 범위와 한계를 적는다.
- `learning_additions.md`의 `[수업 개념]`, `[프로젝트 적용]`, `[프로젝트 추가]`, `[모델 추가]` 표시를 사용한다.
- 수업에서 사용했다는 주장은 실제 수업 파일에서 확인한 근거에 한한다. 프로젝트 추가라는 표시는 개념 자체가 수업에 없었다는 뜻으로 사용하지 않는다.
- 새 모델은 선택 근거와 차원·입력 한도·실행 방식, 교체 시 재청킹·재임베딩 및 저장 버전 검토가 필요한지를 남긴다.
- 관련 개인 노트북과 `learning_additions.md`의 목록도 갱신한다. 단순 주석 편집에서는 기존 코드·셀 번호·저장된 결과를 보존한다.
- 미구현 기능과 미검토 자료를 구현·검토 완료로 표시하지 않는다.
- 개인 작업 범위를 유지하고 팀원 파일·공통 설정을 주석 정리 때문에 수정하지 않는다.
