# PRD | 자동차 사용설명서 챗봇

## 1. 프로젝트 개요

자동차 실소유자가 차량 사용 중 궁금한 점을 질문하면, PDF 사용설명서를 기반으로 답변하는 RAG AI 에이전트 챗봇이다. 데이터 분석 및 AI·머신러닝 부트캠프에서 배운 내용과 코드를 활용해 구현한다.

## 2. 목표 및 사용자

- **사용자:** 지원 차량을 실제 소유한 운전자
- **서비스 목표:** 차량 기능, 조작 방법, 경고등 및 관리 정보를 쉽게 확인
- **학습 목표:** 팀원 모두 데이터 전처리부터 RAG 에이전트 구현까지 전체 과정 경험

## 3. 데이터 범위

차종별 PDF 사용설명서의 **텍스트와 이미지**를 수집한다.

- 텍스트: 기능 설명, 사용 절차, 주의사항 등
- 이미지: 버튼·조작부 그림, 경고등, 기능 안내 도식 등
- 텍스트와 이미지를 차종, 문서, 페이지 정보로 연결
- 이미지에 주변 설명이나 캡션을 연결해 검색하고, 답변에 관련 이미지를 함께 표시

## 4. 핵심 기능

| 기능 | 설명 |
|---|---|
| 차량 선택 | 4개 차종 중 자신의 차량 선택 |
| 질문·답변 | 선택한 차량의 설명서를 검색해 자연어로 답변 |
| 이미지 안내 | 설명에 필요한 관련 이미지를 함께 제공 |
| 출처 표시 | 답변과 이미지의 원본 문서·페이지 표시 |
| 후속 질문 | 같은 차량에 대한 대화 맥락 유지 |
| 예외 처리 | 질문이 모호하면 추가 질문, 근거가 없으면 확인 불가 안내 |

다른 차종의 정보를 섞지 않으며, 선택 사양은 적용 조건을 함께 안내한다.

## 5. 구현 및 협업 방식

팀원 4명이 각각 차종 1개를 담당한다.

각자 **PDF 텍스트·이미지 추출 → 전처리 → 검색 데이터 구축 → 검색·원문 조회 도구 구현 → 답변 생성 → 내부 테스트**를 수행한다.

완성한 에이전트는 공통 입출력 규격으로 하나의 챗봇 UI에 통합한다. UI·통합·가이드·대시보드 작업은 추가로 분담한다.

## 6. 최종 산출물

| 산출물 | 내용 |
|---|---|
| 통합 챗봇 | 4개 차종의 설명서 기반 질의응답 및 관련 이미지 제공 |
| 데이터·도구 가이드 | 사용 PDF, 텍스트·이미지 처리 방식, 모델·도구, 지원 범위 안내 |
| 품질 대시보드 | 팀 내부 테스트의 답변·출처 정확성, 이미지 관련성, 응답 시간 및 실패 사례 표시 |

## 7. 범위 및 완료 기준

고객 평가셋과 만족도 수집은 제외한다. 품질은 팀 내부 테스트로 확인한다. 웹 검색, 차량 제어, 실제 고장 진단, 사용자 이미지 업로드는 초기 범위에 포함하지 않는다.

완료 기준은 다음과 같다.

- 4개 차종 에이전트가 공통 UI에서 동작한다.
- PDF의 텍스트와 이미지가 검색·답변에 활용된다.
- 답변과 이미지의 출처 페이지를 확인할 수 있다.
- 데이터·도구 가이드와 내부 테스트 기반 대시보드를 제공한다.

차종·연식, 기술 스택, 개발 일정 및 내부 테스트 규모는 팀 협의로 확정한다.
